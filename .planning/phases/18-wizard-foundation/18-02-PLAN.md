  - Return array of links

- collectSingleLink(): Promise<Link>
  - Type: select from common options (linkedin, github, website, twitter, other)
  - URL: input with basic URL validation
  - Label (optional): input for display name

<task type="auto">
  <name>Task 2: Create experience prompt flow with bullets</name>
  <files>packages/cli/src/wizard/prompts/experience.ts</files>
  <action>
Create the work experience prompt flow:

**prompts/experience.ts:**
- Import input, confirm from @inquirer/prompts
- Import pc from picocolors
- Import WorkExperience from @gottz/cv-core
- Import validateDate, createValidatingInput from ../validation.ts
- Import WizardMode from ../types.ts

- collectExperience(mode: WizardMode, existing: WorkExperience[]): Promise<WorkExperience[]>
  - Start with copy of existing array
  - Show count: pc.cyan(`\nWork Experience (${entries.length} added)`)
  - Call collectSingleExperience() for new entry
  - Push to array
  - Prompt: 'Add another work experience?' (default: false)
  - Loop until user says no
  - Return updated array

- collectSingleExperience(mode: WizardMode, existing?: WorkExperience): Promise<WorkExperience>
  - Company (required):
    - Message: 'Company name *:'
    - Default: existing?.company
  - Role (required):
    - Message: 'Job title/role *:'
    - Default: existing?.role
  - Start date (required):
    - Message: 'Start date (YYYY-MM) *:'
    - Default: existing?.startDate
    - Validate: validateDate
  - End date:
    - Message: 'End date (default: Present):'
    - Default: existing?.endDate ?? 'present'
    - Validate: validateDate (allows 'present')
  - Location (detailed mode only):
    - Message: 'Location (City, Country):'
    - Default: existing?.location
  - Bullets (always):
    - Call collectBullets()
    - Show existing bullets as context
  - Tech stack (detailed mode only):
    - Call collectTechStack()

- collectBullets(existing?: string[]): Promise<string[]>
  - Per RESEARCH.md: "Repeated input prompts with 'Add another bullet?' or empty Enter to finish"
  - Show existing bullets if any
  - Message: 'Achievement/responsibility bullet (empty to finish):'
  - Loop collecting bullets until empty input
  - Minimum 1 bullet required (re-prompt if 0)
  - Return array of bullet strings

- collectTechStack(existing?: string[]): Promise<string[]>
  - Message: 'Technologies used (comma-separated, or empty to skip):'
  - Default: existing?.join(', ')
  - Split input by comma and trim
  - Return array of tech strings

Update prompts/index.ts to export experience functions.
