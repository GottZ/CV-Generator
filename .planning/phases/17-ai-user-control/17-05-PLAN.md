     - Clone original content
     - For each item in state.accepted:
       - Replace item.original with item.suggested (or the edited/regenerated version)
     - For each [item, editedContent] in state.edited:
       - Replace item.original with editedContent
     - Note: state.skipped items are NOT applied (keep original)

     - Build a replacement map: Map<original string, replacement string>

     - For edited: map original -> edited content

     - Apply replacements sequentially
     - Handle case where original might appear multiple times:

   - Modify improveAction function:

     a) After option parsing, add TTY check:
        - If not options.json and not options.acceptAll and not options.dryRun:
          - Call ensureInteractiveMode()

     b) Keep existing AI generation logic (spinner, runImproveStage, etc.)

     c) After getting result, convert to ReviewItem[]:
        - For each job in result.jobImprovements:
          - For each bullet in job.bullets:
            - Create ReviewItem: {
                section: `${job.role} at ${job.company}`,
                original: bullet.original,
                suggested: bullet.improved,
                weaknessType: bullet.weaknessType (if available),
                generateFn: create wrapper that calls AI again for this specific bullet
              }

     d) Handle different modes:
        - If options.dryRun:
          - Display all suggestions with diff (no interactive prompts)
          - Exit without writing
        - If options.acceptAll:
          - Accept all suggestions automatically
          - Proceed to write confirmation
        - Otherwise (interactive mode):
          - const reviewState = await runReviewSession(reviewItems)
          - If reviewState.accepted.length === 0 and reviewState.edited.size === 0:
            - Log "No changes accepted."
            - Exit without writing

     e) Apply changes and write:
        - Read original cv.md content
        - const newContent = applyReviewedChanges(originalContent, reviewState)
        - const changes = {
            accepted: reviewState.accepted.length,
            skipped: reviewState.skipped.length,
            edited: reviewState.edited.size
          }
        - const result = await safeWriteCvFile(cvPath, newContent, changes)
        - If !result.success: exit (user declined or error)

     f) Update state and show next steps (existing logic)
