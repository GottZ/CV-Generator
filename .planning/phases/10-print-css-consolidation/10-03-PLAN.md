# Phase 10 Plan 03: Fix Page Margins in Print CSS

**Goal:** Restore page margins by removing `padding: 0;` from _print.css and regenerate visual regression baselines.

## Context

The _print.css file contains `padding: 0;` on line 18 which overrides the template's `var(--page-margin)` padding (20-30mm depending on template). This line was not present in the original template CSS and should be removed.

## Root Cause

```css
/* Current _print.css line 18 */
padding: 0;  /* This removes the template's page margin */
```

The comment says "Puppeteer margins handle page spacing" but this is incorrect:
1. Puppeteer margins only apply during PDF generation
2. HTML print preview (browser Ctrl+P) needs CSS padding for margins
3. Visual regression tests use HTML with print media emulation, not Puppeteer

## Tasks

### Task 1: Remove padding: 0 from _print.css

**Action:** Edit `templates/_shared/partials/_print.css`

Remove lines 17-18:
```css
/* Remove padding for print - Puppeteer margins handle page spacing */
padding: 0;
```

The .cv-page rule should become:
```css
.cv-page {
  box-shadow: none;
  margin: 0;
  width: 100%;
  min-height: auto;
}
```

**Verification:**
```bash
grep "padding: 0" templates/_shared/partials/_print.css
# Expected: No matches
```

### Task 2: Regenerate visual regression baselines

**Action:** Run visual regression tests and update baselines

```bash
# In Docker for consistency
docker build -f Dockerfile.test -t cv-test .
docker run -v $(pwd)/tests/__screenshots__:/workspace/tests/__screenshots__ cv-test bun run test:visual --update-snapshots
```

Or locally if Docker not available:
```bash
bun run test:visual --update-snapshots
```

**Verification:**
- Visual inspection: screenshots should show page content with visible margins
- All tests pass with new baselines

### Task 3: Manual verification

**Action:** Verify PDF and HTML output both show correct margins

1. Generate a test PDF: `bun run dev -- examples/alex-chen/cv.md -o test.pdf`
2. Open test.pdf - should have ~20-25mm margins
3. Generate HTML: `bun run dev -- examples/alex-chen/cv.md -o test.html`
4. Open test.html in browser, press Ctrl+P - print preview should show same margins

**Verification:**
- PDF has visible margins matching template --page-margin value
- HTML print preview matches PDF margins
