<task type="auto">
  <name>Task 2: Create regeneration module with similarity detection</name>
  <files>
    packages/cli/src/ai/review/regeneration.ts
    packages/cli/src/ai/review/index.ts
  </files>
  <action>
1. Create `packages/cli/src/ai/review/regeneration.ts`:
   - Import `input, select` from '@inquirer/prompts'
   - Import `pc` from 'picocolors'

   - Define `RegenerationAttempt` interface: { text: string; temperature: number }

   - Create `jaccardSimilarity(str1: string, str2: string): number`:
     - Split both strings into word sets (lowercase, split on whitespace)
     - Calculate intersection size
     - Calculate union size
     - Return intersection.size / union.size

   - Create `async regenerateWithGuidance(options)`:
     - Parameters: { original: string, currentSuggestion: string, history: RegenerationAttempt[], generateFn: (guidance: string, temperature: number) => Promise<string> }
     - Prompt user: "What would you like different?" with input prompt
     - Show example text: "(e.g., 'more specific metrics', 'focus on leadership', 'shorter')"
     - Calculate temperature: start at 0.7, bump by 0.1 per attempt (cap at 1.0)
     - Call generateFn with guidance and temperature
     - Check similarity with previous attempt (if history exists):
       - If > 0.8 similarity: log "Result similar to previous. Increasing variety..."
       - Auto-bump temperature by 0.1 (cap at 1.0)
     - Update history (keep last 5 attempts)
     - Return { newSuggestion, history }

   - Create `async selectFromHistory(history: RegenerationAttempt[], current: string): Promise<string>`:
     - Display numbered history with truncation (60 chars)
     - Mark current with " <-- current"
     - Use select prompt with options:
       - Each history item
       - "r. Regenerate again" option -> returns '__regenerate__'
     - Return selected text or '__regenerate__'

   - Create `truncate(text: string, maxLength: number): string`:
     - If text.length <= maxLength: return text
     - Otherwise: return text.slice(0, maxLength - 3) + '...'

2. Update `packages/cli/src/ai/review/index.ts`:
   - Add exports from regeneration.ts
  </action>
