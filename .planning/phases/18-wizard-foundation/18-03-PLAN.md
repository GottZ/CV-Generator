<task type="auto">
  <name>Task 1: Create education prompt flow</name>
  <files>packages/cli/src/wizard/prompts/education.ts</files>
  <action>
Create the education prompt flow:

**prompts/education.ts:**
- Import input, confirm from @inquirer/prompts
- Import pc from picocolors
- Import Education from @gottz/cv-core
- Import validateDate, createValidatingInput from ../validation.ts
- Import WizardMode from ../types.ts

- collectEducation(mode: WizardMode, existing: Education[]): Promise<Education[]>
  - Start with copy of existing array
  - Show count: pc.cyan(`\nEducation (${entries.length} added)`)
  - Call collectSingleEducation() for new entry
  - Push to array
  - Prompt: 'Add another education entry?' (default: false)
  - Loop until user says no
  - Return updated array

- collectSingleEducation(mode: WizardMode, existing?: Education): Promise<Education>
  - Institution (required):
    - Message: 'Institution name *:'
    - Default: existing?.institution
  - Degree (required):
    - Message: 'Degree/Certificate *:'
    - Default: existing?.degree
    - Help text: e.g., "B.Sc.", "MBA", "Fachinformatiker"
  - Field (optional):
    - Message: 'Field of study:'
    - Default: existing?.field
    - Help text: e.g., "Computer Science"
  - Start date (required):
    - Message: 'Start date (YYYY-MM) *:'
    - Default: existing?.startDate
    - Validate: validateDate
  - End date (required):
    - Message: 'End date (YYYY-MM) *:'
    - Default: existing?.endDate
    - Validate: validateDate
  - Location (detailed mode only):
    - Message: 'Location:'
    - Default: existing?.location
  - Honors (detailed mode only):
    - Message: 'Honors/GPA (optional):'
    - Default: existing?.honors
  - Notes (detailed mode only):
    - Message: 'Additional notes (optional):'
    - Default: existing?.notes

Update prompts/index.ts to export education functions.

  </verify>

<task type="auto">
  <name>Task 2: Create skills prompt flow by category</name>
  <files>packages/cli/src/wizard/prompts/skills.ts</files>
  <action>
Create the skills by category prompt flow:

**prompts/skills.ts:**
- Import input, confirm, checkbox from @inquirer/prompts
- Import pc from picocolors
- Import SkillCategory, Skill from @gottz/cv-core
- Import WizardMode from ../types.ts

- collectSkills(mode: WizardMode, existing: SkillCategory[]): Promise<SkillCategory[]>
  - Start with copy of existing array
  - Show existing categories if any
  - Prompt: 'Add a skills category?' (default: true if empty, false if has entries)
  - If yes, call collectSingleSkillCategory()
  - Loop with 'Add another skills category?' until user says no
  - Return updated array

- collectSingleSkillCategory(mode: WizardMode, existing?: SkillCategory): Promise<SkillCategory>
  - Category name:
    - If quick mode, offer select from common categories:
      - Languages, Frameworks, Databases, Cloud, Tools, Other
    - If detailed mode, allow custom input with suggestions
    - Message: 'Category name *:'
    - Default: existing?.name
  - Skills in category:
    - Call collectSkillsInCategory()
    - Per schema: returns Skill[] with name and optional level

- collectSkillsInCategory(mode: WizardMode, existing?: Skill[]): Promise<Skill[]>
  - Message: 'Skills in this category (comma-separated):'
  - Default: existing?.map(s => s.name).join(', ')
  - Parse comma-separated input into Skill[] with just names
  - If detailed mode, optionally prompt for proficiency level per skill:
    - Only if user wants (prompt: 'Add proficiency levels?')
    - Levels: 'expert', 'proficient', 'familiar', or skip
  - Return Skill[] array

- Common skill categories constant:
  ```typescript
  const COMMON_CATEGORIES = [
    { value: 'Languages', name: 'Languages (e.g., JavaScript, Python)' },
    { value: 'Frameworks', name: 'Frameworks (e.g., React, Express)' },
    { value: 'Databases', name: 'Databases (e.g., PostgreSQL, MongoDB)' },
    { value: 'Cloud', name: 'Cloud & DevOps (e.g., AWS, Docker)' },
    { value: 'Tools', name: 'Tools (e.g., Git, VS Code)' },
    { value: 'custom', name: 'Custom category...' },
  ];
  ```

Update prompts/index.ts to export skills functions.
  </action>
