  <action>
Add parsing functions following the existing parseExperienceEntries/parseEducationEntries patterns:

**parseProjectEntries(content: string): Project[]**
Expected markdown format:
```markdown
### Project Name
*2023-01 - present | Lead Developer | open-source*

Project description here.

#### Technologies
- React
- TypeScript

#### Links
- github: https://github.com/user/repo
- demo: https://example.com

**Outcome:** Achieved X% improvement in Y
---
### Next Project
...
```

Parser logic:
1. Split by `---` delimiter
2. Parse `### ` header as name
3. Parse `*meta*` line for dates, role, type (pipe-separated)
4. Collect description paragraphs until subsection
5. Parse `#### Technologies` or `#### Tech Stack` as techStack array
6. Parse `#### Links` as links array (format: `- type: url` or `- url`)
7. Parse `**Outcome:**` as outcome
8. Handle `highlight: true` in meta line for highlighting flag

Sorting: highlighted projects first, then by startDate descending (newest first). If no dates, maintain markdown order.

**parseCertificationEntries(content: string, warnings: ParseError[], startLine: number): Certification[]**
Expected markdown format:
```markdown
### AWS Solutions Architect - Associate
*Amazon Web Services | 2023-05 | expires 2026-05*

Credential ID: ABC123
https://verify.aws.com/ABC123
---
### Next Certification
...
```

Parser logic:
1. Split by `---` delimiter
2. Parse `### ` header as name
3. Parse `*meta*` line: `issuer | date | expires expiryDate` (pipe-separated)
4. Parse `Credential ID: XXX` line
5. Parse standalone URL as verificationUrl

Validation: If expiryDate is in the past, push warning to warnings array per CONTEXT.md:
```typescript
warnings.push({
  type: 'warning',
  line: startLine + lineNum,
  message: `Certification "${cert.name}" has expired (${cert.expiryDate})`,
  suggestion: 'Consider removing or noting the expiration status',
});
```

- Add `certifications` building (NOT localized - call parseCertificationEntries directly for each 'certifications' section)
