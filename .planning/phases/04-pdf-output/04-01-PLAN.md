<task type="auto">
  <name>Task 3: Create pdf-generator.ts with ATS-optimized PDF generation</name>
  <files>packages/cli/src/lib/pdf-generator.ts</files>
  <action>
    Create PDF generator module that converts HTML to PDF with ATS optimization.

    Interface (see types section below for full definitions):
    - PdfOptions: htmlPath, outputPath, name, locale, footer config, margins, timeout
    - PdfResult: path, bytes, pages

    Function `generatePdf(options: PdfOptions): Promise<PdfResult>`:
    1. Get browser via getBrowser()
    2. Create new page
    3. Navigate to `file://${htmlPath}` with waitUntil: 'networkidle0'
    4. Wait for fonts: `await page.evaluateHandle('document.fonts.ready')`
    5. Inject ATS print CSS (ligatures disabled) via `page.addStyleTag()`
    6. Build footer from options.footer config (see defaults below)
    7. Call page.pdf() with format, margins, header/footer templates
    8. Close page in finally block (prevent memory leaks per RESEARCH.md Pitfall 5)
    9. Return { path: outputPath, bytes: pdfBuffer.length, pages }

    **Types to export:**
    ```typescript
    export interface FooterConfig {
      enabled: boolean;          // Whether to show footer (default: true)
      showName: boolean;         // Whether to include name (default: true)
      showPageNumbers: boolean;  // Whether to include page numbers (default: true)
      template?: string;         // Custom template (overrides above flags)
    }

    export interface PdfOptions {
      htmlPath: string;
      outputPath: string;
      name: string;
      locale: string;
      footer?: FooterConfig;     // Configurable footer (OUT-07)
      margins?: { top?: string; bottom?: string; left?: string; right?: string; };
      timeout?: number;
    }

    export interface PdfResult {
      path: string;
      bytes: number;
      pages: number;
    }
    ```

    **Default footer logic (satisfies OUT-07 "configurable"):**
    - If `footer.template` provided: use it directly
    - If `footer.enabled === false`: empty header/footer
    - Otherwise build from flags: "${name} - Page X of Y" with i18n

    **i18n page format:**
    - "Page <span class='pageNumber'></span> of <span class='totalPages'></span>" (en)
    - "Seite <span class='pageNumber'></span> von <span class='totalPages'></span>" (de)

    **ATS print CSS injection:**
    ```css
    @media print {
      * { font-variant-ligatures: none !important; font-feature-settings: "liga" 0, "clig" 0 !important; }
      .theme-toggle { display: none !important; }
    }
    ```
  </action>
  <verify>
    - `bun run typecheck` passes
    - File exports generatePdf, PdfOptions, PdfResult, FooterConfig
    - Footer template includes pageNumber and totalPages spans
    - FooterConfig interface has enabled, showName, showPageNumbers, template fields
    - ATS CSS includes font-variant-ligatures: none
    - Page closed in finally block
  </verify>
  <done>PDF generator with configurable i18n footer and ATS-safe text extraction</done>
