```nunjucks
{# Contact block macro - renders name, contact info, and links #}
{% macro contact(contactData, locale) %}
<header class="contact">
  <h1>{{ contactData.name }}</h1>
  <div class="contact-info">
    {% if contactData.email %}<span class="contact-item">{{ contactData.email }}</span>{% endif %}
    {% if contactData.phone %}<span class="contact-item">{{ contactData.phone }}</span>{% endif %}
    {% if contactData.location %}<span class="contact-item">{{ contactData.location }}</span>{% endif %}
  </div>
  {% if contactData.links and contactData.links | length > 0 %}
  <div class="contact-links">
    {% for link in contactData.links %}
    <a href="{{ link.url }}" class="contact-link">{{ link.label or link.type }}</a>
    {% endfor %}
  </div>
  {% endif %}
</header>
{% endmacro %}
```

**section.njk:**
```nunjucks
{# Section wrapper macro - renders h2 header with localized title #}

</section>
{% endmacro %}
```

  <action>
Update the template loader to:

1. Skip directories starting with underscore (like `_shared`)
2. Respect `private: true` in config.json (hide from list-templates but still usable)
3. Add the `private` field to TemplateConfig type

**loader.ts changes:**

In `discoverTemplates()`, add check at the beginning of the loop:
```typescript
for (const entry of entries) {
  if (!entry.isDirectory()) continue;

  // Skip underscore-prefixed directories (e.g., _shared)
  if (entry.name.startsWith('_')) continue;

  // ... rest of existing logic
```

After parsing config, check for private flag:
```typescript
const config = JSON.parse(configContent) as TemplateConfig;

// Skip private templates from discovery
if (config.private === true) continue;
```

Note: Private templates can still be loaded directly via `getTemplate()` since that doesn't filter. The filter is only on `discoverTemplates()` which populates list-templates.

**types.ts changes:**

Add to TemplateConfig interface:
```typescript
/** Hide template from list-templates command (default false) */
private?: boolean;
/** Minimum cvgen version required for this template */
minVersion?: string;
/** Style configuration for template customization */
style?: {
  /** Primary accent color (hex format) */
  accentColor?: string;
  /** Heading font family */
  fontHeading?: string;
  /** Body text font family */
  fontBody?: string;
  /** Page margins: "narrow" | "normal" | "wide" or number (mm) */
  margins?: string | number;
  /** Color palette overrides */
  colors?: {
    heading?: string;
    body?: string;
    muted?: string;
    border?: string;
    background?: string;
  };
};
```
