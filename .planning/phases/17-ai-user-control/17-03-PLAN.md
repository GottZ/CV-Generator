  <name>Task 1: Create file writer with backup and confirmation</name>
  <files>

  </files>
  <action>
1. Create `packages/cli/src/ai/review/file-writer.ts`:
   - Import `copyFileSync, writeFileSync, existsSync` from 'node:fs'
   - Import `confirm` from '@inquirer/prompts'
   - Import `pc` from 'picocolors'

   - Define `WriteResult` interface: { success: boolean; backupPath?: string; error?: string }
   - Define `ChangeSummary` interface: { accepted: number; skipped: number; edited: number }

   - Create `async safeWriteCvFile(cvPath: string, newContent: string, changes: ChangeSummary): Promise<WriteResult>`:
     - Display summary:
       - pc.bold('\nReview Summary:')
       - `  Accepted: ${pc.green(changes.accepted)}`
       - `  Skipped:  ${pc.yellow(changes.skipped)}`
       - `  Edited:   ${pc.blue(changes.edited)}`
     - Prompt with confirm:
       - message: `Write changes to ${cvPath}?`
       - default: false (safe default per CONTEXT.md)
     - If user declines:
       - Log pc.dim('Changes discarded.')
       - Return { success: false }
     - Create backup:
       - If backup already exists (cv.md.bak), use timestamped name: `${cvPath}.${Date.now()}.bak`
       - Otherwise use `${cvPath}.bak`
       - Use copyFileSync(cvPath, backupPath)
       - Log pc.dim(`Backup created: ${backupPath}`)
     - Write new content with writeFileSync(cvPath, newContent, 'utf-8')
     - Log pc.green(`Updated: ${cvPath}`)
     - Return { success: true, backupPath }
     - Wrap in try/catch - on error return { success: false, error: message }

2. Update `packages/cli/src/ai/review/index.ts`:
   - Add exports from file-writer.ts
  </action>
  <verify>

    - WriteResult and ChangeSummary types exported
  </verify>
  <done>
    - File writer requires explicit confirmation
    - Backup created before writing
    - Timestamped backup if previous backup exists

  </done>

1. Create `packages/cli/src/ai/review/tty-check.ts`:

   - Create `isTTY(): boolean`:
     - Return process.stdin.isTTY === true

   - Create `getTerminalWidth(): number`:
     - Return process.stdout.columns || 80

   - Create `ensureInteractiveMode(options?: { force?: boolean }): void`:
     - If options?.force: return (bypass check)
     - If !process.stdin.isTTY:
       - Log pc.red('Error: Interactive mode requires a terminal.')
       - Log empty line
       - Log 'For non-interactive use:'
       - Log '  --json           Output suggestions as JSON'
       - Log '  --accept-all     Accept all suggestions without review'
       - Log '  --dry-run        Show changes without writing'
       - Call process.exit(1)
