<task type="auto">
  <name>Task 1: Add long-entry class detection to experienceEntry macro</name>
  <files>templates/_shared/macros/entry.njk</files>
  <action>
Modify the `experienceEntry` macro to conditionally add a `.long-entry` class when the entry has 15 or more bullets. This triggers the existing CSS rule `.entry.long-entry { break-inside: auto; }` already present in `_print.css`.

Change line 3 from:
```nunjucks
<article class="entry experience-entry">
```

To:
```nunjucks
<article class="entry experience-entry{% if job.bullets and job.bullets | length >= 15 %} long-entry{% endif %}">
```

This uses Nunjucks' built-in `length` filter to count bullet points and conditionally add the class.

Rationale from CONTEXT.md:
- "Very long single entries (15+ bullets): keep job header + first bullets together, break within bullet list"
- "Individual bullet points are atomic - never break mid-bullet"

The existing `_print.css` already has:
```css
.entry.long-entry {
  break-inside: auto;
  page-break-inside: auto;
}
```

And `.bullet-item { break-inside: avoid; }` keeps individual bullets intact.
  </action>
  <verify>
Run: `grep "long-entry" templates/_shared/macros/entry.njk`
Confirm: The experienceEntry macro includes conditional long-entry class
  </verify>
  <done>
Experience entries with 15+ bullets automatically receive the `.long-entry` class, allowing page breaks within their bullet lists while keeping individual bullets atomic.
  </done>
</task>

Since projects don't typically have extensive bullet lists like experience entries, we'll check for projects that have both a long description AND multiple techStack items AND outcome. This indicates a substantial project entry.

Change line 42 from:


To:

Projects with 10+ tech stack items indicate a complex, multi-faceted project that may benefit from internal page breaks.

Note: Experience entries use 15 bullets as threshold, projects use 10 tech items. These thresholds are conservative - most entries will NOT be marked as long-entry, preserving the default "keep together" behavior.
