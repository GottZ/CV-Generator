<task type="auto">
  <name>Task 1: Update shared print CSS partial with improved pagination</name>
  <files>templates/_shared/partials/_print.css</files>
  <action>
Update the shared print CSS partial with smarter pagination rules:

```css
/* Print styles for PDF generation */
@page {
  size: A4 portrait;
  margin: 0;
}

@media print {
  body {
    background: white;
  }

  .cv-page {
    box-shadow: none;
    margin: 0;
    width: 100%;
    min-height: auto;
    /* Remove padding for print - Puppeteer margins handle page spacing */
    padding: 0;
  }

  /* Sections CAN span pages - don't force entire sections to new page */
  .section {
    /* Allow sections to break across pages */
    break-inside: auto;
    page-break-inside: auto;
    /* But prefer not to leave orphan/widow lines */
    orphans: 3;
    widows: 3;
  }

  /* Section headers should stay with some content */
  .section h2 {
    break-after: avoid;
    page-break-after: avoid;
  }

  /* Individual entries should stay intact when possible */
  .entry {
    break-inside: avoid;
    page-break-inside: avoid;
  }

  /* But if entry is too long, allow break rather than huge gap */
  .entry.long-entry {
    break-inside: auto;
    page-break-inside: auto;
  }

  /* Bullet lists can break between items */
  .bullet-list {
    break-inside: auto;
    page-break-inside: auto;
  }

  /* But individual bullet items should stay intact */
  .bullet-item {
    break-inside: avoid;
    page-break-inside: avoid;
  }

  /* Skills section - allow break between categories */
  .skill-category {
    break-inside: avoid;
    page-break-inside: avoid;
  }

  /* Contact header should never break */
  .contact {
    break-inside: avoid;
    page-break-inside: avoid;
    break-after: avoid;
    page-break-after: avoid;
  }

  /* Don't show URL in printed links - ATS parses href directly */
  a[href]::after {
    content: none;
  }

  /* Hide theme toggle in print */
  .theme-toggle {
    display: none !important;
  }
}
```

Key changes:
- Sections now allow breaks (break-inside: auto) instead of avoiding all breaks
- Added orphans/widows support to avoid single lines at page boundaries
- Section headers avoid breaking from their content
- Individual entries still avoid breaking mid-entry
- Bullet lists can break between items, but not within an item
- Contact header stays together and doesn't break after

  </verify>

```typescript
const ATS_PRINT_CSS = `
@media print {
	/* Disable ligatures for ATS text extraction (ATS-01) */
	* {
		font-variant-ligatures: none !important;
		font-feature-settings: "liga" 0, "clig" 0 !important;
	}

	/* Force light mode for PDF */
	:root {
		color-scheme: light !important;
	}

	/* Improved pagination - sections can span pages */
	.section {
		break-inside: auto;
		page-break-inside: auto;
		orphans: 3;
		widows: 3;
	}

	/* Section headers stay with content */
	.section h2 {
		break-after: avoid;
		page-break-after: avoid;
	}

	/* Entries stay intact when reasonable */
	.entry {
		break-inside: avoid;
		page-break-inside: avoid;
	}

	/* Bullet items stay intact */
	.bullet-item {
		break-inside: avoid;
		page-break-inside: avoid;
	}

	/* Contact stays together */
	.contact {
		break-inside: avoid;
		page-break-inside: avoid;
		break-after: avoid;
	}

	/* Remove interactive elements */
	.theme-toggle {
		display: none !important;
	}
}
`;
```

This ensures the ATS CSS injection overrides any template-specific rules with the correct pagination behavior.
