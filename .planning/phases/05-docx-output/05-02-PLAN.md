```typescript
  cv: CVData,

  imagesDir?: string,
```

**Section order (mirroring PDF per CONTEXT.md):**
1. Name (Heading 1)
2. Contact info (email | phone | location as Normal text)
3. Links (if present, as clickable text)
4. Summary section (Heading 2 + Normal paragraphs)
5. Experience section (Heading 2 + entries with bold company, dates, bullets)
6. Education section (Heading 2 + entries)
7. Skills section (Heading 2 + category groups with bullet items)

**Word built-in styles (per RESEARCH.md Pattern 3):**
- Name: `heading: HeadingLevel.HEADING_1`
- Section headers: `heading: HeadingLevel.HEADING_2`
- Body text: default (Normal style)

**i18n section headers:**
Use existing i18n pattern from templates package or inline:
```typescript

  en: { summary: 'Summary', experience: 'Experience', education: 'Education', skills: 'Skills' },

};
```

**Experience entry structure:**
```typescript
// Company | Role (bold)
```

**Spacing:**
Use `spacing: { before: X, after: Y }` in TWIPs (1 line ~ 240 TWIPs for 12pt text).

**IMPORTANT:** Use HeadingLevel enum, NOT custom style names, so Navigation Pane works (RESEARCH.md Pitfall 2).

<task type="auto">
  <name>Task 2: Add image embedding with loadImageForDocx</name>
  <files>packages/cli/src/lib/docx-sections.ts</files>
  <action>
Add image loading and embedding function to docx-sections.ts.

**Function signature:**
```typescript
export async function loadImageForDocx(imagePath: string): Promise<Paragraph | null>
```

**Implementation:**
1. Check if file exists using `Bun.file(imagePath).exists()`
2. Read file as buffer: `Buffer.from(await file.arrayBuffer())`
3. Get dimensions using sharp: `await sharp(buffer).metadata()`
4. **CRITICAL:** Return null if width/height missing (RESEARCH.md Pitfall 1 - corrupt file without dimensions)
5. Scale to max width (~150px for profile photos) while maintaining aspect ratio
6. Create ImageRun with `transformation: { width, height }` (both required!)

**ImageRun structure:**
```typescript
new ImageRun({
  data: buffer,
  transformation: {
    width: scaledWidth,
    height: scaledHeight,
  },
  altText: {
    title: 'Profile photo',
    description: 'Candidate profile photograph',
    name: 'profile',
  },
});
```

**Integration with buildDocumentContent:**
If `imagesDir` is provided and a profile image exists (e.g., `profile.jpg`, `photo.png`), include it after contact info.

Check for common image names:
- profile.jpg, profile.png
- photo.jpg, photo.png
- avatar.jpg, avatar.png

Use the first match found.
