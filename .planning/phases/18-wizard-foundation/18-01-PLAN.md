  <name>Task 1: Create wizard types and state machine</name>
  <files>packages/cli/src/wizard/types.ts, packages/cli/src/wizard/state.ts, packages/cli/src/wizard/index.ts</files>
  <action>
Create the wizard type definitions and state management:

**types.ts:**
- Import types from @gottz/cv-core: Contact, WorkExperience, Education, SkillCategory, Project, Certification
- Define WizardMode: 'quick' | 'detailed'
- Define SectionStatus: 'empty' | 'partial' | 'complete'
- Define WizardSection: 'contact' | 'experience' | 'education' | 'skills' | 'projects' | 'certifications'
- Define ValidationResult: { valid: boolean; error?: string; warning?: string }
- Define WizardState interface:
  ```typescript
  interface WizardState {
    contact: Contact | null;
    experience: WorkExperience[];
    education: Education[];
    skills: SkillCategory[];
    projects: Project[];
    certifications: Certification[];
    mode: WizardMode;
    currentSection: WizardSection | null;
    validationIssues: Map<string, string[]>;
    skippedFields: Set<string>;
  }
  ```

**state.ts:**
- createInitialState(mode: WizardMode): WizardState - creates empty state
- createStateFromExisting(cv: CVData, mode: WizardMode): WizardState - pre-populates from existing CV
- getSectionStatus(state: WizardState, section: WizardSection): SectionStatus
  - 'empty': no data in section
  - 'partial': some data but incomplete (e.g., experience with 0 bullets)
  - 'complete': section has valid data
- isMinimumViable(state: WizardState): boolean
  - Returns true if contact exists AND at least one of (experience, education, skills) has data
  - Per CONTEXT.md: "Minimum viable CV: contact info + at least one section"
- getArrayCount(state: WizardState, section: WizardSection): number - returns count for array sections

**index.ts:**
- Export all types and state functions
- Re-export for future wizard functions

Use picocolors import pattern from existing codebase.

Create the menu navigation and validation layer:

**menu.ts:**
- Import select, Separator from @inquirer/prompts
- Import pc from picocolors
- Import getSectionStatus, getArrayCount from ./state.ts
- Import WizardState, SectionStatus from ./types.ts

- formatMenuItem(name: string, status: SectionStatus, optional: boolean, count?: number): string
  - Per CONTEXT.md checkmark style:
    - complete: pc.green('✓')
    - partial: pc.yellow('◐')
    - empty + optional: pc.dim('○')
    - empty + required: pc.red('✗')
  - Include count if provided: "Experience (2)"
  - Include optional marker if optional: pc.dim(' (optional)')

- showMainMenu(state: WizardState): Promise<'contact' | 'experience' | 'education' | 'skills' | 'projects' | 'certifications' | 'finish' | 'cancel'>
  - Build choices array with formatMenuItem for each section
  - Contact is required, experience/education/skills partially required (need one), projects/certifications optional
  - Add Separator before finish/cancel
  - Use select() with message 'CV Wizard - Select section:'
  - Set loop: false (no wrap-around)

- selectMode(): Promise<WizardMode>
  - Per CONTEXT.md: "Quick/detailed mode offered at start"
  - Quick: "Essential fields only (faster)"
  - Detailed: "All fields (comprehensive)"

**validation.ts:**
- Import input from @inquirer/prompts
- Import pc from picocolors

- validateDate(value: string): true | string
  - Accept: empty (optional), 'present', YYYY-MM, YYYY-M, Month YYYY, MM/YYYY
  - Return error message if invalid: 'Enter date as YYYY-MM (e.g., 2023-01) or "present"'

- validateEmail(value: string): true | string
  - Accept empty (optional) or valid email format
  - Return error message: 'Please enter a valid email address'

- validateRequired(value: string, fieldName: string): true | string
  - Reject empty strings with '[fieldName] is required'

- createValidatingInput(config: {
    message: string;
    required?: boolean;
    validate?: (value: string) => true | string;
    atsWarning?: (value: string) => string | null;
    default?: string;
  }): Promise<string>
  - Per CONTEXT.md: "Re-prompt on first error; if same invalid value submitted again, continue but track"
  - Track previous value and attempt count internally
  - If same invalid value submitted twice, log warning and return true
  - If atsWarning returns a warning, display it with pc.yellow() but continue

Update index.ts to export menu and validation functions.
