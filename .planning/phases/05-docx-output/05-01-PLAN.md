<task type="auto">
  <name>Task 2: Create docx-generator.ts with footer and metadata</name>
  <files>packages/cli/src/lib/docx-generator.ts</files>
  <action>
Create the core DOCX generator module at `packages/cli/src/lib/docx-generator.ts`.

**Interfaces:**

```typescript
interface DocxOptions {
  cv: CVData;
  locale: string;
  outputPath: string;
}

interface DocxResult {
  path: string;
  bytes: number;
}
```

**Document structure:**
1. Document with metadata properties (creator, title, subject, description)
2. Single section with page margins (matching PDF: ~20mm top/bottom, ~25mm left/right in TWIPs)
3. Footer with i18n "Name - Page X of Y" using native Word field codes

**i18n page format (per CONTEXT.md):**
- English: "Page X of Y"
- German: "Seite X von Y"

**Key imports from docx:**
- Document, Packer, Paragraph, TextRun
- HeadingLevel, AlignmentType
- Header, Footer, PageNumber

**Footer implementation:**
Use `PageNumber.CURRENT` and `PageNumber.TOTAL_PAGES` for native Word field codes (not VBA macros per CONTEXT.md).

**Document properties (per CONTEXT.md):**
- creator: "CV Generator"
- title: "{name} - CV"
- subject: "Curriculum Vitae"
- description: "Curriculum Vitae for {name}"

**Output:**
Use `Packer.toBuffer()` (NOT toBlob() - that's browser-only per RESEARCH.md Pitfall 3).
Write buffer to outputPath using `Bun.write()`.

**IMPORTANT pitfall avoidance (from RESEARCH.md):**
- Font sizes use half-points: 24pt = size: 48
- Margins use TWIPs: 1 inch = 1440 TWIPs, 1mm ~ 57 TWIPs
- Always specify transformation dimensions for ImageRun (handled in Plan 02)
