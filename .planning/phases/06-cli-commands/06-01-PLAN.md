  <action>
Create packages/cli/src/lib/prompts.ts with:

2. OverwriteChoice type: `'overwrite' | 'skip' | 'cancel'`

3. promptOverwrite(dirPath: string): Promise<OverwriteChoice>
   - Create readline interface with process.stdin/stdout
   - Ask: `Directory "${dirPath}" exists. [o]verwrite, [s]kip, or [c]ancel? `
   - Normalize answer: toLowerCase().trim()
   - Map: 'o'/'overwrite' -> 'overwrite', 's'/'skip' -> 'skip', else -> 'cancel'
   - IMPORTANT: Always close readline in finally block (RESEARCH.md Pitfall 4)
   - Return choice

4. promptName(): Promise<string>
   - Create readline interface
   - Ask: `Enter person name (e.g., john-doe): `
   - Return trimmed input (empty string if user just hits enter)
   - Always close readline in finally block

5. Export both functions and OverwriteChoice type

Per CONTEXT.md: Interactive prompts for init command when directory exists or name not provided.
  </action>
