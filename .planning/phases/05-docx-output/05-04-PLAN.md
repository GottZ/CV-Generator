  <files>packages/cli/src/lib/docx-style-extractor.ts</files>
  <action>
Create a new module that extracts CSS custom properties from template styles.css and maps them to docx library equivalents:

1. Define DocxStyleConfig interface:
```typescript
interface DocxStyleConfig {
  // Font sizes in half-points (docx convention)
  fontSizes: {
    name: number;      // --font-size-name: 24pt -> 48 half-points
    section: number;   // --font-size-section: 14pt -> 28 half-points
    subsection: number; // --font-size-subsection: 12pt -> 24 half-points
    body: number;      // --font-size-body: 11pt -> 22 half-points
    small: number;     // --font-size-small: 10pt -> 20 half-points
  };
  // Colors as hex strings (no # prefix for docx)
  colors: {
    heading: string;   // --color-heading: #1a1a1a -> "1a1a1a"
    body: string;      // --color-body: #333333 -> "333333"
    accent: string;    // --color-accent: #2563eb -> "2563eb"
    muted: string;     // --color-muted: #666666 -> "666666"
  };
  // Font families
  fonts: {
    heading: string;   // --font-heading: Arial
    body: string;      // --font-body: Arial
  };
  // Spacing in TWIPs (1mm ~ 57 TWIPs)
  spacing: {
    pageMargin: number;  // --page-margin: 20mm -> 1134 TWIPs
    sectionGap: number;  // --spacing-lg: 24px -> ~360 TWIPs
    entryGap: number;    // --spacing-md: 16px -> ~240 TWIPs
  };
}
```

2. Implement `extractStylesFromCss(cssContent: string): DocxStyleConfig` function:
   - Parse CSS custom properties using regex
   - Extract --font-size-* values (e.g., "24pt" -> 24)
   - Extract --color-* values (e.g., "#1a1a1a" -> "1a1a1a")
   - Extract --font-* values (first font family name)
   - Extract --spacing-* and --page-margin values

3. Add helper functions:
   - `mapFontSizeTwips(ptValue: number): number` - converts pt to half-points (multiply by 2)
   - `mapColorHex(cssColor: string): string` - strips # prefix from hex color
   - `mapSpacingTwips(pxValue: number): number` - converts px to TWIPs (~15 TWIPs per pixel)
   - `mapMmToTwips(mmValue: number): number` - converts mm to TWIPs (57 TWIPs per mm)

4. Export DEFAULT_DOCX_STYLES constant as fallback when CSS parsing fails

DO NOT use Puppeteer for this task - extract directly from CSS file content.
