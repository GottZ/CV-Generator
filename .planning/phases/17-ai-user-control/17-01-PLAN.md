  <files>

  </files>
  <action>
1. Create `packages/cli/src/ai/review/weak-bullet-detector.ts`:
   - Define `WeaknessType` = 'lacks_quantification' | 'missing_outcome' | 'too_generic' | 'passive_voice'
   - Define `WEAKNESS_REASONS` record mapping each type to human-readable reason
   - Create `detectWeakness(bullet: string): WeaknessType | null`:
     - Check for quantification: no numbers, percentages, or metrics -> 'lacks_quantification'
     - Check for outcome: no result words (achieved, improved, reduced, increased, delivered, launched, saved, generated) -> 'missing_outcome'
     - Check for generic verbs: (helped, worked on, assisted, was involved, participated) -> 'too_generic'
     - Check for passive voice: (was responsible, were tasked, been assigned, was given) -> 'passive_voice'
     - Return first weakness found or null if none
   - Create `displayWeakBulletWarning(bullet: string, weakness: WeaknessType): void`:
     - Format: `pc.yellow('[!]') + ' ' + bullet + ' ' + pc.dim('-- ' + WEAKNESS_REASONS[weakness])`
     - Import picocolors for coloring

2. Update `packages/cli/src/ai/review/index.ts`:
   - Add exports from weak-bullet-detector.ts
  </action>
