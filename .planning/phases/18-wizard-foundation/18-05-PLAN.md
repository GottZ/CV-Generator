<task type="auto">
  <name>Task 2: Create markdown writer module</name>
  <files>packages/cli/src/wizard/markdown-writer.ts</files>
  <action>
Create the markdown writer that outputs cv.md format:

**markdown-writer.ts:**
- Import { mkdir, writeFile } from 'node:fs/promises'
- Import path from 'node:path'
- Import WizardState from ./types.ts
- Import ora from 'ora' (WIZ-13: progress indication)

- generateMarkdown(state: WizardState, locale: string = 'en'): string
  - Follow exact format from scaffolder.ts createExampleMarkdown()
  - Build lines array and join with '\n'

  - Frontmatter section:
    ```
    ---
    name: {contact.name}
    email: {contact.email}  # if set
    phone: {contact.phone}  # if set
    location: {contact.location}  # if set
    links:  # if any
      - url: {link.url}
        type: {link.type}
        label: {link.label}  # if set
    ---
    ```

  - Experience section (if any):
    ```
    ## Experience `{locale}`

    ### {role} at {company}
    *{startDate} - {endDate}{ | location}*

    - {bullet1}
    - {bullet2}

    #### Technologies  # if techStack
    - {tech1}
    - {tech2}

    ---  # separator between entries
    ```

  - Education section (if any):
    ```
    ## Education `{locale}`

    ### {degree}
    *{institution} | {startDate} - {endDate}*

    {field}
    {honors}
    {notes}

    ---
    ```

  - Skills section (if any):
    ```
    ## Skills `{locale}`

    ### {categoryName}
    - {skill1}
    - {skill2}
    ```

  - Projects section (if any):
    ```
    ## Projects `{locale}`

    ### {name}

    {description}

    **Technologies:** {techStack.join(', ')}

    **Links:**
    - [{link.type}]({link.url})

    ---
    ```

  - Certifications section (if any - NOT localized per schema):
    ```
    ## Certifications

    ### {name}
    *{issuer} | {date}*

    { Expires: {expiryDate} }
    { Credential ID: {credentialId} }
    { [Verify]({verificationUrl}) }

    ---
    ```

- writeWizardOutput(state: WizardState, personDir: string, locale?: string): Promise<void>
  - Create person directory if needed: await mkdir(personDir, { recursive: true })
  - Use ora spinner per WIZ-13: spinner.start('Writing CV...')
  - Generate markdown: const content = generateMarkdown(state, locale)
  - Write file: await writeFile(path.join(personDir, 'cv.md'), content, 'utf-8')
  - Stop spinner: spinner.succeed('CV saved')

Update index.ts to export markdown writer functions.
