  <name>Task 1: Create projects prompt flow</name>
  <files>packages/cli/src/wizard/prompts/projects.ts</files>
  <action>
Create the projects prompt flow:

**prompts/projects.ts:**
- Import input, confirm, select from @inquirer/prompts
- Import pc from picocolors
- Import Project, ProjectLink from @gottz/cv-core
- Import validateDate from ../validation.ts
- Import WizardMode from ../types.ts

- collectProjects(mode: WizardMode, existing: Project[]): Promise<Project[]>
  - Start with copy of existing array
  - Show count: pc.cyan(`\nProjects (${entries.length} added)`)
  - Prompt: 'Add a project?' (default: false - optional section)
  - If yes, call collectSingleProject()
  - Loop with 'Add another project?' until user says no
  - Return updated array

- collectSingleProject(mode: WizardMode, existing?: Project): Promise<Project>
  - Name (required):
    - Message: 'Project name *:'
    - Default: existing?.name
  - Description (optional):
    - Message: 'Description (brief overview):'
    - Default: existing?.description
  - Tech stack:
    - Message: 'Technologies used (comma-separated):'
    - Default: existing?.techStack?.join(', ')
    - Parse into string array
  - Project type (detailed mode only):
    - Select: personal, professional, open-source, freelance
    - Default: existing?.type ?? 'personal'
  - Role (detailed mode only):
    - Message: 'Your role (e.g., Lead Developer, Contributor):'
    - Default: existing?.role
  - Outcome (detailed mode only):
    - Message: 'Outcome/result (optional):'
    - Default: existing?.outcome
  - Dates (detailed mode only):
    - Start date: Message: 'Start date (YYYY-MM, optional):'
    - End date: Message: 'End date (YYYY-MM or "present", optional):'
  - Links:
    - Prompt: 'Add a project link?' (GitHub, demo, etc.)
    - Call collectProjectLinks() if yes

- collectProjectLinks(existing?: ProjectLink[]): Promise<ProjectLink[]>
  - Show existing links if any
  - Loop collecting links via collectSingleProjectLink()
  - Stop when user says no to 'Add another link?'

- collectSingleProjectLink(): Promise<ProjectLink>
  - Type: select from common options (github, demo, npm, docs, website, other)
  - URL (required): input with basic URL validation
  - Label (optional): display name

Update prompts/index.ts to export projects functions.

- collectSingleCertification(mode: WizardMode, existing?: Certification): Promise<Certification>

  - Issuer (required):

    - Default: existing?.issuer
    - Help: e.g., "Amazon Web Services"
  - Date (required):

    - Default: existing?.date

  - Expiry date (optional):
    - Message: 'Expiry date (YYYY-MM, or empty if no expiry):'
    - Default: existing?.expiryDate

  - Credential ID (detailed mode only):
    - Message: 'Credential ID (optional):'
    - Default: existing?.credentialId
  - Verification URL (detailed mode only):
    - Message: 'Verification URL (optional):'
    - Default: existing?.verificationUrl
  - Logo (detailed mode only):
