# Printing Your CV

This guide explains how to print your CV from the generated HTML file using your browser. The printed output will closely match the PDF generated by the CLI.

## Quick Start

1. Generate your CV with HTML output:
   ```bash
   cvgen build yourname modern --format html
   ```

2. Open the HTML file in **Google Chrome** (recommended)

3. Press **Ctrl+P** (Windows/Linux) or **Cmd+P** (macOS)

4. Select **Save as PDF** as the destination

5. Click **Save**

## Recommended Browser

**Google Chrome** is recommended for printing because:
- The CV generator uses Puppeteer (Chrome's rendering engine) for PDF generation
- Chrome's print output will most closely match the CLI-generated PDF
- Other browsers may render fonts and page breaks differently

Other Chromium-based browsers (Edge, Brave, Opera) should also work well.

## Print Settings

For best results, use these print dialog settings:

### Page Size
- **Paper size:** A4 (or Letter for US)
- **Margins:** Default (the CSS handles margins)
- **Scale:** 100%

### Appearance
- **Background graphics:** Enabled (checked)
  - This ensures colors and backgrounds print correctly
- **Headers and footers:** Disabled (unchecked)
  - The CLI PDF has a custom footer; browser print does not include this

### Layout
- **Pages:** All
- **Layout:** Portrait

## Step-by-Step Guide

### Windows / Linux

1. Open the `.html` file in Chrome
2. Press `Ctrl+P` to open the print dialog
3. Click "Destination" and select "Save as PDF"
4. In "More settings":
   - Set margins to "Default"
   - Check "Background graphics"
   - Uncheck "Headers and footers"
5. Click "Save"
6. Choose a location and filename

### macOS

1. Open the `.html` file in Chrome
2. Press `Cmd+P` to open the print dialog
3. Click the "PDF" dropdown at bottom-left
4. Select "Save as PDF"
5. In print settings:
   - Check "Print backgrounds"
   - Set paper size to A4
6. Click "Save"

## Known Differences

When printing from the browser, you may notice these differences compared to the CLI-generated PDF:

### Footer

**CLI PDF**: Includes a footer with your name and page numbers (e.g., "John Doe - Page 1 of 2")

**Browser Print**: Does not include this footer

This is expected. The CLI injects the footer at PDF generation time, which browsers cannot replicate.

### Text Optimization

**CLI PDF**: Disables font ligatures for better ATS (Applicant Tracking System) text extraction

**Browser Print**: Uses standard font rendering

If you're submitting to an ATS, use the CLI-generated PDF for best compatibility.

### Page Distribution

**CLI PDF**: Uses a two-pass algorithm to optimize page distribution and avoid near-empty last pages

**Browser Print**: Uses standard browser pagination

Multi-page CVs may have slightly different page breaks, though the overall layout should be very similar.

## Troubleshooting

### Colors Not Printing

Make sure "Background graphics" is enabled in the print dialog. Without this, background colors and some styling won't appear.

### Text Looks Different

Ensure you're using Chrome or a Chromium-based browser. Firefox and Safari use different rendering engines that may produce different results.

### Page Breaks in Wrong Places

The CSS should handle page breaks correctly. If content is splitting inappropriately:
1. Try adjusting the browser zoom to 100%
2. Ensure "Scale" is set to 100% in print settings
3. If the issue persists, use the CLI-generated PDF instead

### Margins Look Wrong

Set margins to "Default" in the print dialog. The CSS includes its own margin rules that should work with default browser margins.

## When to Use CLI PDF Instead

Use the CLI-generated PDF (`cvgen build yourname modern`) when:
- Submitting to an Applicant Tracking System (ATS)
- You need the name/page number footer
- Exact page break positions matter
- Sharing the file digitally (smaller file size, optimized metadata)

Use browser printing when:
- You need to quickly print a physical copy
- You've made manual HTML edits and want to print them
- CLI is not available

## See Also

- [CLI Documentation](./CLI.md) - Complete command reference
- [Customization Guide](./CUSTOMIZATION.md) - Modifying templates and styles
- [FAQ](./FAQ.md) - Common questions and answers
