2. ValidateOptions interface:
   - locale?: string
   - quiet?: boolean
   - json?: boolean

3. ValidationStats interface (per RESEARCH.md Pattern 6):
   - sections: number
   - jobs: number
   - degrees: number
   - skillCategories: number
   - locales: string[]

   - EXIT_PARSE_ERROR = 1
   - EXIT_FILE_ERROR = 3
   - EXIT_VALIDATION_ERROR = 4

5. gatherStats(cv: CVData): ValidationStats
   - Count sections: Object.keys(cv).filter(k => k !== 'contact').length
   - Count jobs: sum of all experience entry arrays
   - Count degrees: sum of all education entry arrays
   - Count skillCategories: sum of all skills arrays
   - Collect locales from all sections

6. validateAction(name: string, options: ValidateOptions): Promise<void>

   a. Create console with options
   b. Build paths: peopleDir, personDir, cvPath

   c. Check person directory exists:
      - If not, list available people (readdir peopleDir)
      - Throw personNotFoundError(name, availablePeople)

   d. Check cv.md exists:
      - If not: Error with "Try: Create cv.md in people/{name}/"

   e. Parse CV:
      - Call parseCV(cvContent)
      - If errors: format as CLI-05/CLI-06 requires
        - Show each error with line number if available
        - Include "Try: ..." suggestion for common issues
        - Exit with EXIT_PARSE_ERROR

   f. Check requested locale (if --locale specified):
      - Get available locales from CV
      - If requested not in available: warning but continue

   g. Gather and display stats:
      - const stats = gatherStats(cv)
      - Per CONTEXT.md: "Valid: 4 sections, 3 jobs, 2 degrees"
      - Also show: skill categories, locales found

   h. JSON output if --json:
      - { status: 'success', stats: { ... } }
